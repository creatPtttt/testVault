# Recommended open-source UI packs for RuneDelve

Already integrated:
- Tiny RPG — Dragon Regalia GUI (CC0) → modal shells, portrait frames, stash slots
- Tiny RPG — Dark Dwellers GUI (CC0) → vault stat plates
- Kenney Fantasy UI Borders (CC0) → optional ornaments under `public/assets/ui/kenney-fantasy-borders/`
- Kenney UI Pack RPG Expansion (CC0) → legacy panels

Strong next downloads (dark fantasy fit):
1. Dark ARPG UI — https://opengameart.org/content/dark-arpg-ui (CC-BY 4.0, needs attribution)
2. Dark World Asset Pack — https://kaishido.itch.io/dark-world (CC0 inventory frame)
3. Parchment GUI — https://opengameart.org/content/parchment-gui (CC0 9-patch panels/slots)
4. Fantasy UI Borders — already on disk (Kenney CC0)

Avoid for this art direction:
- Bright white/minimal Kenney sample layouts as primary chrome
- Neon / cyberpunk UI packs
